# 最終課題の概要（PDF作成用の下書き）

アカウントID：142097

## 目的とタスク
Gazebo上のCRANE+ V2が、お辞儀とハンド開閉を行った後、アームを振って机上のボールを箱の的へ転がす。

## AIの利用
お辞儀・準備は固定コード。打撃区間のみ、コードで生成した教師動作の実測ログからACTで模倣学習する。教師1エピソードを20Hz・66フレームへ変換し、Colab T4で1500ステップ学習。実行時は関節状態からAIが指令を予測し、ROSへ送る。物体画像・座標は入力しない固定配置の実験。

## 工夫と結果
固定演出と学習する区間を分離。初回AI動作では的を外れた。教師動作64指令に対し初回AIは55指令で、推論時間が周期へ余分に加算されていたため修正。修正後の試行では65指令となり、利用者が命中を目視確認した。録画時にもばらつきがあり、安定した成功率は測定していない。

## 制約・考察
最小限の1エピソードであり、他配置への汎化は主張しない。接触センサーによる成功判定は未実装。今後は複数の独立した教師エピソード、接触検出、指令時刻と推論遅延の記録で評価を改善したい。実機では検証していない。
